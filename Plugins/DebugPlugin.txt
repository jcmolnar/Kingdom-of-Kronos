This plugin is not part of the bov plugin official release.  Instead it's the Bov do what you want but don't blame me if it crashes release

The general purpose is to help figure out issues if you are having it (including slowdowns).

This can patch into functions so using this plugin might cause worse performance, but can be used to help analyze performance (or which areas you might need to optimize)

===================
Published Functions
===================
Debug::functions - Pretty much loads up the "stack" analysis code.  This will spam echo when you access a variable that isn't assigned
Debug::DisplayFunctionStats - Shows each functions "runtime" and the times called.  Must have called Debug::functions(); already
Debug::ResetFunctionStats - Resets things

broadcastDebugPort(port]) - When you call this, it opens a socket broadcasting to 127.0.0.1:port.  It essentially sends UDP packets locally.
	When used, debug::functions will be spamming UDP packets (can be useful to see what function was last called before a crash)
