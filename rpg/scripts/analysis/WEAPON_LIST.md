## Variable Reference

All weapons use the following variable structure:
- **$AccessoryVar[WeaponName, $AccessoryType]** - Weapon category (Sword/Polearm/Bludgeon)
- **$AccessoryVar[WeaponName, $SpecialVar]** - Damage value (format: "6 X" where X is damage)
- **$AccessoryVar[WeaponName, $Weight]** - Weight in pounds
- **$AccessoryVar[WeaponName, $MiscInfo]** - Description text
- **$SkillType[WeaponName]** - Required skill type ($SkillSlashing, $SkillPiercing, or $SkillBludgeoning)
- **$ItemCost[WeaponName]** - Purchase cost (either hardcoded or generated via GenerateItemCost())
- **$SkillRestriction[WeaponName]** - Skill requirement string (format: "$SkillType SkillLevel [RemortRequirement]")

Additional weapon-related variables:
- **$RangeTable[$AccessoryType]** - Range modifier (Sword: 4, Polearm: 5, Bludgeon: 4)
- **$DelayFactorTable[$AccessoryType]** - Attack speed modifier (Sword: 0.9, Polearm: 1.2, Bludgeon: 1.1)
- **$CostFactorTable[$AccessoryType]** - Cost modifier (Sword: 0.7, Polearm: 0.7, Bludgeon: 0.7)
